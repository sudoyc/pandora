## 当前布局

### 整体结构

```
┌──────────────────────────────────────────────────────────────────┐
│  主内容区 (Min(1))                                                │
│  ┌─────────────┬─────────────┬──────────────┐                    │
│  │ 画廊列表 35% │ 缩略图网格35%│ 信息面板 30% │  ← Browse 模式     │
│  │             │             │              │                    │
│  └─────────────┴─────────────┴──────────────┘                    │
├──────────────────────────────────────────────────────────────────┤
│  状态栏 (Length(1))                                               │
└──────────────────────────────────────────────────────────────────┘
```

### Browse 模式 — 三栏布局

```
┌─ Homepage ──────┬─ Thumbnails ────┬─ Gallery Info ──┐
│ ▶ [cover] Title │  ┌──┐ ┌──┐ ┌──┐│  ┌──────────┐   │
│   [    ] Author │  │  │ │  │ │  ││  │  Cover   │   │
│   ★★★☆☆ Manga  │  └──┘ └──┘ └──┘│  │  Image   │   │
│   2024-01-15 20p│  ┌──┐ ┌──┐ ┌──┐│  └──────────┘   │
│                 │  │  │ │  │ │  ││  Title           │
│   [cover] Title │  └──┘ └──┘ └──┘│  Uploader        │
│   [    ] Author │  ┌──┐ ┌──┐ ┌──┐│  ★★★★☆ 4.5       │
│   ★★★★☆ Doujin │  │  │ │  │ │  ││  Pages: 20       │
│   2024-02-20 35p│  └──┘ └──┘ └──┘│  Posted: ...     │
│                 │                 │  Tags:           │
│   ...           │                 │   female: ...    │
│                 │                 │   male: ...      │
└─────────────────┴─────────────────┴─────────────────┘
 [Homepage p1] j/k:nav l:open /:search ...    ↓2
```

左栏：画廊列表
- 每行 4 行高 (CARD_HEIGHT=4)
- 左侧 cover 图片区域，固定 8 列宽 (COVER_WIDTH=8)
- 右侧文字：标题、上传者、评分+分类标签、日期+页数
- 选中项：`▶` 前缀 + `Rgb(50,50,80)` 背景高亮

中栏：缩略图网格
- 自动计算网格：每个缩略图 `THUMB_W=14, THUMB_H=8`
- 按行列排列，超出区域截断
- 加载中显示 `Color::DarkGray` 占位文字

右栏：信息面板
- 上方：cover 大图 (高度 = 面板宽度 * 3/4，最大 20 行)
- 下方：标题、上传者、评分、页数、日期、标签列表
- 标签按 namespace 分组，namespace 用 `Color::Cyan`，tag 用默认色

### Reader 模式 — 双栏布局

```
┌─ Pages ──┬─ Title — Page 5/20 ──────────────────┐
│   [001]  │                                       │
│   [002]  │                                       │
│   [003]  │           (全尺寸图片)                  │
│   [004]  │                                       │
│ ▶ [005]  │                                       │
│   [006]  │                                       │
│   [007]  │                                       │
└──────────┴───────────────────────────────────────┘
```

- 左侧页码列表：20% 宽度，当前页 `Color::Yellow` + bold + `▶` 前缀
- 右侧图片查看器：80% 宽度，`StatefulImage` 填充
- 加载进度：居中 `Gauge`，最大 40 列宽，`Color::Cyan`

### 搜索覆盖层

```
┌─ (Browse 背景) ─────────────────────────────────┐
│                                                  │
│  ┌─ Suggestions ──────────────┐                  │
│  │ ▶ female:stockings         │                  │
│  │   丝袜                      │                  │
│  │   female:pantyhose         │                  │
│  │   连裤袜                    │                  │
│  └────────────────────────────┘                  │
│  [Doujinshi✓][Manga✓][Artist CG✗]... ★min:2     │
├──────────────────────────────────────────────────┤
│ 🔍 search query█                                 │
└──────────────────────────────────────────────────┘
```

- 搜索输入栏：底部 1 行，`Rgb(30,30,40)` 背景，`🔍` 前缀
- 建议弹窗：最大 12 行高 × 50 列宽，`Color::Cyan` 边框
- 分类过滤栏：1 行，`[Name✓]` 绿色 / `[Name✗]` 灰色

### 下载覆盖层

- 居中浮动面板，70% 终端宽度（最大 60 列）
- 每个任务 2 行：状态标签 + 标题 / 进度条
- 状态颜色：queued=黄, downloading=青, complete=绿, error=红

### 帮助覆盖层

- 居中浮动面板，60×20，`Color::Yellow` 边框
- 三列快捷键表格

## 配色方案

| 颜色 | 用途 |
|------|------|
| `DarkGray` | 边框、次要文字、空状态、占位符 |
| `Yellow` | 星级评分、列表选中项、帮助边框、queued 状态、当前页码 |
| `Cyan` | 选中指示符 `▶`、搜索光标、建议/下载边框、进度条、downloading 状态 |
| `Gray` | 上传者、页码列表非当前项、搜索翻译行 |
| `White` | 状态栏前景 |
| `Red` | 错误信息、error 状态 |
| `Green` | 已包含分类、complete 状态 |
| `Rgb(50,50,80)` | 选中卡片背景 |
| `Rgb(30,30,40)` | 搜索输入栏背景 |

分类标签颜色（`category_colors()`）：每个分类有独立的前景/背景色对。

## 已知问题与待改进设计

### P0 — 功能性问题

1. **渲染卡顿**: 浏览大图时极端卡顿，无法加载第一页以外的内容
2. **本地画廊缩略图走网络**: 应从 library file 端点直接读取本地文件，不走 daemon image proxy
3. **下载进度条显示不正确**: WS 事件对接可能有误，需检查 phase 字段处理
4. **右栏 cover 尺寸异常**: 渲染后图片可能出现尺寸不对的问题

### P1 — 视觉改进

5. **Tag 显示中文翻译**: daemon 的 tag suggest API 返回中文翻译，信息面板的 tag 列表应优先显示中文，无中文时 fallback 到英文
6. **右栏 cover 居中**: 当前 cover 图片左对齐，应水平居中
7. **左栏 cover 宽度一致**: 当前 `COVER_WIDTH=8` 固定列宽保证高度一致，但视觉上应保证宽度一致（即所有 cover 等宽，高度自适应）。可能需要调整三栏比例或 CARD_HEIGHT

### P2 — 体验优化

8. **虚拟滚动**: 画廊列表和缩略图网格应实现虚拟滚动，只渲染可见区域
9. **图片缓存预热**: 进入 Browse 时预加载可见范围内的 cover 和缩略图
10. **渐进式图片加载**: 先显示低分辨率占位，再替换为高清图

## 关键尺寸常量

| 常量 | 值 | 位置 | 说明 |
|------|---|------|------|
| `CARD_HEIGHT` | 4 | `ui/gallery_card.rs` | 列表每行高度 |
| `COVER_WIDTH` | 8 | `ui/browse.rs` | 列表 cover 图片宽度 |
| `THUMB_W` | 14 | `ui/thumb_grid.rs` | 缩略图网格单元宽度 |
| `THUMB_H` | 8 | `ui/thumb_grid.rs` | 缩略图网格单元高度 |
| `PRELOAD_WINDOW_LOCAL` | 10 | `main.rs` | 本地阅读预加载窗口 ±10 页 |
| `PRELOAD_WINDOW_ONLINE` | 3 | `main.rs` | 在线阅读预加载窗口 ±3 页 |
| `PRELOAD_CONCURRENT` | 3 | `main.rs` | 预加载并发数 |
| 三栏比例 | 35/35/30 | `ui/browse.rs` | 列表/缩略图/信息面板 |
| Reader 比例 | 20/80 | `ui/reader.rs` | 页码列表/图片查看器 |
| Cover 高度 | `width*3/4, max 20` | `ui/info_panel.rs` | 右栏 cover 图片高度 |
